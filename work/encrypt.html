Encrypt a protected case study

Paste the HTML for the protected part of a case study, choose a passcode, and this produces the encrypted block to drop into the page. Everything happens in this browser tab — nothing is uploaded, and the text never leaves your machine.

Two things that matter. Only the encrypted block goes into git, never the plain text — so don't paste confidential content anywhere else in the repo. And pick a real passphrase: the ciphertext is public, so a short or guessable passcode can be attacked offline. Four or more unrelated words is plenty.

  1. Open work/project-17.html.
  2. Find <script type="application/json" id="gate-payload">.
  3. Replace the single JSON line between the tags with the block above.
  4. Commit and push. Test with the passcode before you send it to anyone.
